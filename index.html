Supervised by design

Agents do not get permission by default.

01

Start with contextEvery mission starts with the objective, constraints, evidence needs, completion criteria, and expected output.

02

Use the least access neededAgents and tools receive only the access required for an authorized task.

03

Show the evidenceResearch keeps sources, assumptions, uncertainty, and open questions visible.

04

Require human approvalPublishing, payments, outreach, destructive changes, sensitive security actions, and consequential decisions require explicit approval.

05

Check the resultALPHA verifies outputs and escalates when evidence or authorization is insufficient.
