# ALPHA lead follow-up pilot

Open `index.html` in a browser. Load the fictional example to see inquiry intake, duplicate detection, a response draft, approval of the exact text, manual-send status, and CSV export. No server or API key is needed. Data remains in that browser's local storage. Do not enter actual customer data into this demo; it has no authentication, shared storage, retention controls, or backups.

## Paid pilot scope to propose

One client, one inbound inquiry source, one owner, first response plus one follow-up, and human approval before sending. Connect to the client's real tools only after an agreed scope, access review, and a separate implementation. Do not describe this demo as a deployed ALPHA runtime or connected CRM.

**Baseline:** count inquiries and record time to first response and booked appointments for the prior 14 days, by source and inquiry type. **Pilot:** track the same for 14 days. Report both aggregate and segment results, with lead volume and quality changes noted. **Scale gate:** client confirms that the workflow improves response time or booking handling without unmanageable review work. Otherwise stop or revise.
