# Security Policy

## Supported version

Only the current `main` branch is supported.

## Reporting

Please report suspected security issues privately to the repository owner. Do not include credentials, personal data, or exploit payloads in a public issue.

## Release controls

- Dependency-free static site
- No backend or privileged actions
- No external scripts or analytics
- Restrictive Content Security Policy
- Human-approval language preserved as a demonstration
- No secrets permitted in the repository

Jarvis approval controls shown on the site are illustrative and do not enforce authorization for any external system.
